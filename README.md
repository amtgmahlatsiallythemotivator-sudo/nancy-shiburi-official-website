# Nancy Shiburi – Official Website

Responsive Next.js website for Nancy Katrina Shiburi, South African gospel artist.

## Run locally

```bash
npm install
npm run dev
```

## Deployment

Import `amtgmahlatsiallythemotivator-sudo/nancy-shiburi-official-website` into Vercel. No enquiry email/API configuration is required: booking and contact forms compose a WhatsApp message to Nancy's supplied number and open WhatsApp for the visitor to review and send. Direct email is available at `nancyshiburi7@gmail.com`.

Replace the clearly identified gallery and portrait placeholders with artist-approved images when available. Configure the custom domain in Vercel after deployment.
